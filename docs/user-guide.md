# Руководство по интерфейсу Transaction Import

Transaction Import подготавливает редактируемые операции из текста банковской выписки. Проверьте результат перед экспортом: приложение скачивает выбранный JSON batch и не записывает операции в финансовый ledger. Для внешнего LLM используйте только синтетические или обезличенные финансовые данные.

## Панели приложения

Верхняя навигация содержит пять панелей:

- **Сессии** — создание и продолжение импорта выписки;
- **Фоновые задачи** — настройка периодического импорта и просмотр его запусков;
- **MCP** — состояние настроенных интеграций и обновление их списка;
- **Настройки** — общие инструкции, категории и правила обработки продавцов;
- **Поддержка** — вопросы об интерфейсе и использовании приложения.

## Создание и продолжение импорта

1. В панели «Сессии» нажмите «Новый импорт».
2. В активной сессии вставьте текст выписки в поле «Выписка или уточнение» и нажмите «Отправить». Отдельной загрузки файла в текущем интерфейсе нет.
3. Проверьте результат в панели «Состояние выписки» и черновик в панели «Операции». Черновик остаётся редактируемым.
4. Чтобы исправить запись, измените её поля или описание в редакторе операции и сохраните. Можно также отправить однозначное уточнение сообщением. Проверьте отмеченные ошибки и элементы «Нужно проверить».
5. Выберите нужные валидные операции и нажмите «Экспортировать». Браузер скачает JSON batch; сам экспорт не записывает данные в финансовый ledger.

Для продолжения обработки отправьте следующую выписку или уточнение в текущей сессии: новые операции добавятся к черновику, точные дубликаты будут пропущены. Для независимого импорта создайте новую сессию. Сохранённую сессию можно снова открыть после перезагрузки приложения.

### Состояния выписки

- **Не начато** — операции ещё не подготовлены.
- **Содержит ошибки** — проверьте сообщения об ошибках и исправьте проблемные записи.
- **Готово к экспорту** — выбранные валидные операции можно скачать в JSON.

## Настройки

Настройки активной сессии позволяют выбрать provider, model и reasoning mode для следующих сообщений этой сессии. В панели «Настройки» доступны общие инструкции, категории, подтверждённые решения и правила нормализации продавцов. Общие инструкции применяются к следующим запросам во всех сессиях; настройки новой сессии не изменяют уже выбранную конфигурацию другой сессии.

## Фоновые задачи

Создайте периодическое задание в панели «Фоновые задачи». Оно связано с отдельной редактируемой сессией. Последующие запуски добавляют новые результаты в эту сессию и сохраняют ручные правки.

Для задания доступны пауза, возобновление, запуск сейчас и история запусков. Откройте связанную сессию, чтобы просмотреть и при необходимости вручную отредактировать подготовленные операции. Удаление сессии может затронуть связанные задания; перед подтверждением проверьте показанный состав.

## MCP

Панель «MCP» показывает доступность настроенных интеграций и позволяет обновить их список. В ней также отображается доступное пользователю состояние подключённых интеграций. MCP не нужен для обычного ручного импорта текста выписки.

## Поддержка

1. Откройте вкладку «Поддержка» и задайте вопрос о работе интерфейса или пользовательской функции.
2. Ассистент отвечает по подтверждённым материалам приложения; в чате показывается только ответ, без списка источников.
3. Если документы не подтверждают ответ, ассистент сообщит об ограничении вместо догадки. Переформулируйте вопрос или спросите о другой функции.

## Конфиденциальность данных

Не отправляйте настоящие выписки, операции или персональные данные внешнему LLM provider. Для проверки интерфейса и работы с моделью используйте синтетические или обезличенные данные.
