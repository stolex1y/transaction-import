# Руководство по интерфейсу Transaction Import

Transaction Import подготавливает редактируемые операции из текста банковской выписки. Проверьте результат перед экспортом: приложение скачивает выбранный JSON batch и не записывает операции в финансовый ledger. Для внешнего LLM используйте только синтетические или обезличенные финансовые данные.

## Панели приложения

Верхняя навигация содержит пять панелей:

- **Сессии** — создание и продолжение импорта выписки;
- **Фоновые задачи** — настройка периодического импорта и просмотр его запусков;
- **MCP** — состояние настроенных интеграций и обновление их списка;
- **Настройки** — общие инструкции, категории и правила обработки продавцов;
- **Поддержка** — вопросы об интерфейсе и использовании приложения.

## Создание и продолжение импорта

1. В панели «Сессии» нажмите «Новый импорт».
2. В активной сессии вставьте текст выписки в поле «Выписка или уточнение» и нажмите «Отправить». Отдельной загрузки файла в текущем интерфейсе нет.
3. Проверьте результат в панели «Состояние выписки» и черновик в панели «Операции». Черновик остаётся редактируемым.
4. Чтобы исправить запись, измените её поля или описание в редакторе операции и сохраните. Можно также отправить однозначное уточнение сообщением. Расход, доход и возврат — разные типы операции; возврат не считается доходом. Если направление спорное, проверьте запись до экспорта.
5. Выберите нужные валидные операции и нажмите «Экспортировать». Браузер скачает JSON batch; сам экспорт не записывает данные в финансовый ledger.

Для продолжения обработки отправьте следующую выписку или уточнение в текущей сессии: новые операции добавятся к черновику, точные дубликаты будут пропущены. Для независимого импорта создайте новую сессию. Сохранённую сессию можно снова открыть после перезагрузки приложения.

Если для приложения включена стратегия ветвления, используйте «Создать ветку», чтобы начать отдельную линию работы от текущего состояния. Кнопка «Копировать» у сообщения копирует его текст.

### Представление операций

Переключайте список операций между видом «Таблица» и «Карточки». Кнопка темы в верхней панели включает светлое или тёмное оформление.

### Импорт через Т-Банк MCP

Если интеграция доступна, проверьте её состояние в панели «MCP» и проходите вход в предназначенной для этого форме: вводите номер телефона, SMS-код и пароль, если его запросил банк. Не отправляйте эти данные сообщением ассистенту. В активной сессии запросите операции по счёту и периоду; если счёт нельзя определить однозначно, выберите или уточните нужный счёт. Результат появится в сообщении агента. Проверьте операции и нажмите «Принять операции», чтобы добавить их в черновик: один только просмотр результата черновик не изменяет.

Интеграция Т-Банка работает в режиме чтения и зависит от настроенного MCP-сервера. Её технический контракт не является официальным публичным API банка и может измениться.

### Чеки

Для входа в ФНС нажмите «Войти в ФНС» в панели «MCP»: откроется отдельное окно официального сайта. Телефон, CAPTCHA и SMS-код вводите только там. После успешного входа задайте диапазон дат и, при необходимости, продавца; выберите сводку, чтобы открыть детали чека. Ручной поиск и просмотр деталей не меняют черновик операций.

Для сопоставления чеков с банковскими операциями попросите агента выполнить сопоставление и проверьте результат перед подтверждением операций. Неоднозначная строка может остаться на проверке; отсутствие чека не означает, что банковская операция удалена.

### Состояния выписки

- **Не начато** — операции ещё не подготовлены.
- **Содержит ошибки** — проверьте сообщения об ошибках и исправьте проблемные записи.
- **Готово к экспорту** — выбранные валидные операции можно скачать в JSON.

## Настройки

Настройки активной сессии позволяют выбрать provider, model и reasoning mode для следующих сообщений этой сессии. В панели «Настройки» доступны общие инструкции, категории, подтверждённые решения и правила нормализации продавцов. Общие инструкции применяются к следующим запросам во всех сессиях; настройки новой сессии не изменяют уже выбранную конфигурацию другой сессии.

### Категории и правила магазинов

В «Категориях операций» можно добавлять и редактировать категории, задавать родительскую категорию, тип «Расход» или «Доход» и необязательную подсказку. В операции выбираются конечные категории; неиспользуемую категорию можно архивировать. Правило в разделе «Канонические названия магазинов» задаёт основное название и варианты; при необходимости укажите, учитывать ли числовой суффикс в конце названия.

Предложения агента о постоянном решении появляются как кандидаты в сообщениях. Такое решение попадает в список подтверждённых только после явного подтверждения пользователя.

Раздел «Системные инварианты» показывает обязательные правила приложения; пользовательские инструкции не могут их изменить.

### Память и контекст

Панель «Memory layers» показывает безопасную проекцию данных, вошедших в контекст текущего запроса: недавний диалог, сведения о черновике и применимые общие инструкции или подтверждённые решения. Полный запрос провайдеру в панели не показывается. Если для сессии включены «Sticky facts», отдельная панель показывает используемые в этой сессии факты. Стратегия контекста загружается вместе с сессией и отображается в настройках.

### Токены и ошибки контекста

Панель «Токены вызовов» показывает input, ответ, общий расход, лимит контекста и его занятость. Сумма «За сессию» складывается из успешных вызовов; повторно отправленная история учитывается повторно. Если запрос не помещается в контекст или провайдер завершает его ошибкой, проверьте статус и причину; такой сбой сам по себе не меняет черновик.

## Фоновые задачи

Создайте задание в панели «Фоновые задачи»: задайте название, счета, начальную дату и период в минутах. Приложение создаст связанную редактируемую сессию; откройте её из карточки задания, чтобы проверить или вручную исправить операции. Последующие запуски добавляют результаты в ту же сессию и не перезаписывают ручные правки.

Для задания доступны пауза, возобновление, запуск сейчас и история запусков. Часовой пояс фиксируется по системной зоне сервера при создании. При удалении связанной сессии приложение показывает, какие задания будут затронуты, и просит подтверждение.

## MCP

Панель «MCP» показывает доступность настроенных интеграций и позволяет обновить их список. В ней также отображается доступное пользователю состояние подключённых интеграций. MCP не нужен для обычного ручного импорта текста выписки.


## Поддержка

1. Откройте вкладку «Поддержка» и задайте вопрос о работе интерфейса или пользовательской функции.
2. Ассистент отвечает по подтверждённым материалам приложения. Если они не подтверждают ответ, он сообщает об ограничении вместо догадки.
3. Используйте синтетические или обезличенные примеры; не отправляйте в чат настоящие выписки, реквизиты или секреты.

## Конфиденциальность данных

Не отправляйте настоящие выписки, операции или персональные данные внешнему LLM provider. Для проверки интерфейса и работы с моделью используйте синтетические или обезличенные данные.
